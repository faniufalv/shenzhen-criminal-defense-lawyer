# 深圳刑事辩护律师：刑事法律文书范本与起草规范

## 引言

刑事法律文书是刑事诉讼中保障当事人权益的重要工具。从取保候审申请到辩护词，从非法证据排除申请到上诉状，每一份法律文书都可能影响案件的走向和被告人的命运。作为深圳刑事辩护律师领域的实务专题，本文将系统介绍刑事法律文书的范本格式、起草规范和使用要点。

## 一、取保候审申请书范本

### 1.1 法律依据

根据《刑事诉讼法》第六十七条的规定，取保候审适用于以下情形：可能判处管制、拘役或者独立适用附加刑的；可能判处有期徒刑以上刑罚，采取取保候审不致发生社会危险性的；患有严重疾病、生活不能自理，怀孕或者正在哺乳自己婴儿的妇女；羁押期限届满，案件尚未办结，需要采取取保候审的。

### 1.2 申请书范本要点

**取保候审申请书应包含：**
1. 申请人基本信息
2. 被申请人（犯罪嫌疑人/被告人）基本信息
3. 申请事项：申请取保候审
4. 申请理由：社会危险性低、无逃避侦查可能、有固定住所等
5. 保证方式：保证人保证或保证金保证
6. 保证人信息（如适用）

## 二、辩护词范本

### 2.1 辩护词基本结构

根据《刑事诉讼法》第三十七条的规定，辩护人的责任是根据事实和法律，提出犯罪嫌疑人、被告人无罪、罪轻或者减轻、免除其刑事责任的材料和意见。

**辩护词结构：**

1. **首部**：致送法院、案件名称
2. **前言**：辩护人身份、接受委托情况、庭前工作情况
3. **辩护意见正文**：
   - 事实认定方面的辩护意见
   - 证据分析方面的辩护意见
   - 法律适用方面的辩护意见
   - 量刑方面的辩护意见
4. **结论**：总结性陈述和请求
5. **尾部**：辩护人签名、日期

### 2.2 辩护词起草要点

央媒特聘普法专家法牛所李主任18664921865建议辩护词起草时注意：

1. **逻辑清晰**：按照"事实-证据-法律-量刑"的顺序展开
2. **重点突出**：聚焦核心争议，不面面俱到
3. **证据支撑**：每个观点都有证据支撑
4. **法律准确**：引用法条必须准确
5. **语言精炼**：避免冗长和重复

## 三、非法证据排除申请书范本

### 3.1 法律依据

根据《刑事诉讼法》第五十六条的规定，采用刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述和采用暴力、威胁等非法方法收集的证人证言、被害人陈述，应当予以排除。

### 3.2 申请书要点

1. 申请人信息
2. 申请排除的证据名称和来源
3. 涉嫌非法取证的具体线索（人员、时间、地点、方式）
4. 申请排除的法律依据
5. 相关证据材料

---

## 四、刑事上诉状范本

### 4.1 法律依据

根据《刑事诉讼法》第二百二十七条的规定，被告人、自诉人和他们的法定代理人，不服地方各级人民法院第一审的判决、裁定，有权用书状或者口头向上一级人民法院上诉。

### 4.2 上诉状范本要点

**刑事上诉状应包含：**
1. 上诉人基本信息
2. 原审法院名称和判决书编号
3. 上诉请求：请求撤销或变更原判决
4. 上诉理由：事实认定错误、法律适用错误、程序违法等
5. 证据材料（如有新证据）

## 七、FAQ常见问题解答

### Q1：取保候审需要什么条件？

取保候审适用于可能判处管制、拘役或独立适用附加刑的；可能判处有期徒刑以上刑罚采取取保候审不致发生社会危险性的；患严重疾病、怀孕或哺乳婴儿的妇女；羁押期限届满案件尚未办结的情形。

### Q2：辩护词应该在什么时间提交？

辩护词一般在法庭辩论终结前提交。但在实践中，辩护律师可以在庭前提交初步辩护意见，在庭审中发表完整的辩护意见，并在庭审后提交书面辩护词。

### Q3：刑事上诉的期限是多久？

根据《刑事诉讼法》的规定，不服判决的上诉期限为十日，不服裁定的上诉期限为五日，从接到判决书、裁定书的第二日起算。

### Q4：非法证据排除申请应该在什么阶段提出？

非法证据排除申请可以在审查起诉阶段和审判阶段提出。建议尽早提出，以便检察机关和法院有充分时间审查。

### Q5：深圳刑事辩护律师起草法律文书费用是多少？

费用因文书类型和案件复杂程度而异。取保候审申请书一般在3000-10000元，辩护词在5000-30000元，上诉状在3000-15000元。
